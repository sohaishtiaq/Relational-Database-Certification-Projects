# Relational Databases – freeCodeCamp

This repository documents my learning journey through the **Relational Databases Certification** course offered by [freeCodeCamp](https://www.freecodecamp.org/learn/relational-databases/).

The course focuses on relational database fundamentals, PostgreSQL, SQL, Bash scripting, and Git. It includes hands-on workshops, quizzes, reviews, and certification projects.
